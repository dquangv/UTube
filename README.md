UTube is a video management platform offering core functionalities similar to YouTube. Key features include video CRUD operations, user registration/login, admin statistics, video playback, watch history, liked videos, and search functionality.

This project was developed using Java Servlet, JPA/Hibernate, and JSTL on the backend, with PostgreSQL as the database. The system was built following Agile methodology with a team of 5 members, and responsibilities included requirements analysis, database design, and full-stack implementation.
